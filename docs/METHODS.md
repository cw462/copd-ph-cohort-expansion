# 方法与分析边界

本项目整理既有COPD相关临床记录与CT定量结果，并开展基于原来源PH标签的探索性分类分析。目前尚未完成经过验证的“600例COPD-PH模型”。公开内容用于说明队列整理、质量核查和内部评估方法，不支持临床部署或个体诊断。

分析以冻结的最终运行配置和对应汇总指标为依据。队列规模采用去重后的分析记录口径；“来源标签可用于探索分析”不等于全部病例已经完成独立临床金标准裁决。

| 整理阶段或分析子集 | 记录数 | 来源PH标签 | 来源noPH标签 | 含义 |
| --- | ---: | ---: | ---: | --- |
| 初始合并记录 | 613 | — | — | 用于身份、来源、标签和特征可用性核查 |
| 来源标签准入集合 | 590 | 553 | 37 | 暂缓22条来源标签冲突记录及1条身份关联证据不足记录 |
| 准入集合中已有CT定量 | 443 | 406 | 37 | 具有至少一类既有CT定量来源；不是统一协议的443例CT模型 |
| 混合协议既有特征子集（yu194） | 194 | 157 | 37 | 用于低维模型、协议分层及混杂诊断 |
| 原始CTPA定量子集 | 374 | 371 | 3 | 仅用于流程可行性探索，对照数量极少 |

194条与374条两个特征子集重叠125条，并集为443条，不能相加为568个独立病例。590条准入记录中另有147条缺少既有CT定量；没有通过整块缺失值填补将其加入CT模型。

标签保留原始来源的PH/noPH分类。来源之间发生冲突时单独暂缓，不根据现有压力数值自动改写标签。COPD归属依据既有来源中的病因或影像诊断描述，尚未替代独立临床裁决。GOLD缺失或无效编码保留为严重程度未知，不自动排除这些记录，也不将其解释为noPH。GOLD 1–4限制仅用于单独的敏感性分析。

影像关联优先依赖原始来源记录、明确的检查引用、检查标识与日期，以及可用的DICOM检查信息。姓名或拼音一致只形成候选关联，不能单独完成身份确认、检查确认或标签转移。同一检查的多个目录副本不重复计数。影像位置已找到，也不意味着已完成序列完整性、成像协议、分割质量和CT与右心导管检查（RHC）时间关系的全部核查。

预测变量采用预先固定的低维集合，没有根据本轮结局表现筛选特征：

| 变量 | 定义与单位 |
| --- | --- |
| 年龄 | 既有来源记录中的年龄 |
| 性别 | 既有来源中的类别编码 |
| 全肺容积 | mL |
| 全肺LAA950 | 百分比 |
| 全肺平均密度 | HU |
| 肺血管容积 | mL |
| 动脉BV5 | mL |

五项CT变量沿用既有量化输出的定义。同名指标仍需核对来源模块、解剖范围、单位和成像协议；不同来源或不同平扫/增强协议的数值不自动视为可互换。主分析预测变量不含PH标签派生字段、RHC压力或肺血管阻力、GOLD等级、患者标识、来源路径等可能泄漏标签或身份的信息。来源和成像协议仅在明确标记的混杂诊断或协议调整模型中使用。

逻辑回归比较年龄与性别、五项CT变量，以及两者联合的输入集合。在混合协议子集中，另以相同低维联合输入运行固定配置的随机森林和XGBoost，作为探索性比较。随机森林使用200棵树、最大深度3、最小叶节点样本数5及训练集类别权重；XGBoost使用150棵树、最大深度2、学习率0.03、行列采样比例各0.8、L2正则系数10，类别权重仅由当前训练折计算。未开展全特征筛选或大规模超参数竞赛。

内部评估采用3次重复的分层交叉验证，随机种子为42、2020和2026。队列少数类至少10条时，外层为5折；否则为3折。逻辑回归在每个外层训练集内另做交叉验证：训练集少数类至少6条时使用3折，否则使用2折；按内层ROC AUC在正则化参数C为0.1、1和10之间选择。固定配置的树模型不再进行内层调参。

所有可用的强身份关联键先检查重复，同一分析对象不会同时进入同一折的训练集和测试集；不同模型在相同队列、相同重复下使用相同划分。数值中位数填补、标准化、类别众数填补及独热编码均在相应训练折内拟合，并应用于该折测试集。未使用SMOTE或其他重采样，也未使用测试折选择特征、参数或阈值。

每次重复汇总所有外层测试折的预测，使每个分析对象在该重复中只有一次折外预测。评价指标包括ROC AUC、平均精确率、Brier分数，以及固定0.5阈值下的敏感度、特异度和平衡准确率。报告3次重复的均值与最小值—最大值；该范围反映划分波动，不是置信区间，也不能将3次重复当作3倍独立样本。未设置外部验证集。

为检查成像协议及检查时间的影响，另开展CT、CTA和CTPA协议内分析，以及CT与RHC间隔不超过30天的敏感性分析。30天窗口沿用前期技术试跑的设定，不宣称其为临床指南规定的纳入标准。时间无法可靠解析时不推测日期，也不自动以最近一次历史CT替代指定检查。协议内子集及时间限制子集互有包含，不能累加为新的独立病例。

来源与协议混杂是当前结果的主要限制。混合协议194条记录中，仅使用协议的逻辑回归平均AUC约为0.870，高于年龄、性别与五项CT变量联合模型的约0.824；来源元数据单独建模也可获得很高的区分度。这提示模型可能利用入组和采集流程差异，不能将混合队列AUC直接解释为可推广的病理生理信号。

374条CTPA记录仅有3条noPH对照。其CT5逻辑回归平均AUC约为0.943，3次重复范围约为0.931–0.964，但固定0.5阈值下特异度在每次重复中均为0。较高AUC没有证明模型能识别noPH；该结果仅表明分析流程可运行，不能作为有效临床分类器或充分对照验证的证据。

另收到一份111条记录、285个测量字段的平扫CSV，用于补充来源核查。这份表缺少独立患者标识和检查日期。经候选关联检查，86条可对应到613条主表的候选记录，其中85条位于590条准入集合内，候选来源标签为80条PH、5条noPH；另1条属于暂缓集合。其余包括23条旧NPH表候选和2条未匹配记录。这些均保留为候选，未自动转移临床标签或并入训练。与缺少CT定量的147条记录的候选交集为0，因此目前不能据此声称补齐了这147条的CT特征，也不能把111条全部计作新增病例。

后续仍需完成候选身份与检查关联确认、来源标签裁决、协议与量化定义统一、影像和分割质量检查，并增加可比的noPH对照及独立验证。数据公开范围与复现限制见[数据可用性声明](DATA_AVAILABILITY.md)。
