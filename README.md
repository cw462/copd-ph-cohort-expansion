公开代码、数据整理的汇总结果和探索性实验结果。数据快照截至 **2026-10-21**，公开整理日期为 **2026-10-23**。

**600例完整CT分类训练集尚未完成。** 本仓库记录已经完成的工作及仍需补齐的问题，不提供经过临床验证的诊断模型。

## 已完成的实验

已完成 **11种队列设置、24种队列与模型组合、282次外层拟合**。队列和重复划分有重叠，不能相加作为独立患者数。模型采用5项CT指标作为低维基线，尚未完成全部175/285项特征或影像组学建模。

| 实验 | 平均ROC-AUC | 解释 |
|---|---:|---|
| 194条：年龄、性别 + CT5，逻辑回归 | 0.824 | 扫描协议混合，探索性结果 |
| 194条：年龄、性别 + CT5，随机森林 | 0.668 | 探索性结果，参数与其他模型的差异见方法 |
| 194条：年龄、性别 + CT5，XGBoost | 0.690 | 探索性结果 |
| 194条：仅扫描协议 | 0.870 | 用于检查协议与标签的关联，不是临床预测结果 |
| 590条：仅来源与模态元数据 | 0.991 | 显著来源混杂，不能解释为疾病识别能力 |
| 374条原CTPA：CT5逻辑回归 | 0.943 | 只有3条noPH；阈值0.5的平均特异度为0 |

完整结果见 [模型汇总](results/metrics_summary.csv)、[各次重复结果](results/metrics_by_repeat.csv) 和 [混合模型在各扫描方式内的表现](results/pooled_model_within_protocol_metrics.csv)。

所有AUC均来自内部交叉验证。重复结果的最小值和最大值表示划分波动，**不是置信区间**。没有独立外部测试集，也没有临床部署模型。

## 平扫CSV能补什么

补充表有111条记录、285个CT指标列，其中36列全空。它与旧队列有109条姓名候选关联，包括旧表标为NPH的28条，其中25条原本缺平扫特征。

结合已有旧队列与总表之间的身份关联，形成86条总表候选：85条在590候选层，另1条仍待核。余下为23条旧NPH候选和2条未找到对应的记录。**CSV这一侧仍缺患者ID、检查日期和序列信息，这些关联不能当作确认的同人同次CT；没有转移PH/GOLD标签或加入训练。** 当前没有匹配到147条缺定量清单，不能据此减少该缺口。

详见 [总体数据整理与补充表统计](data_quality/cohort_and_supplement_summary.json)。

## 代码与复现

公开脚本实现模型和交叉验证方法，真实病例清洗与关联记录保留在本地。运行真实实验需要已经完成身份、标签、来源和扫描日期审核的私有输入；公开仓库只提供汇总结果，不提供这些逐例输入。

- [输入字段与运行方式](docs/INPUT_SCHEMA.md)
- [方法与解释边界](docs/METHODS.md)
- [特征含义及单位](docs/feature_dictionary.csv)
- [冻结实验设置](results/experiment_specification.json)
- [独立核对概述](data_quality/verification_summary.json)

`scripts/make_synthetic_example.py` 用独立随机数生成演示数据；它不读取、重采样或改写真实病例。合成数据的结果只用于验证代码能运行，不属于上面的临床来源结果。

安装依赖后，可以在仓库外生成并运行完整的合成示例：

```sh
python -m pip install -r requirements.txt
python scripts/make_synthetic_example.py --output-dir ../synthetic-example
python scripts/run_experiments.py --features ../synthetic-example/features.csv --metadata ../synthetic-example/metadata.csv --ctpa-export ../synthetic-example/ctpa_export.csv --output-dir ../synthetic-run
python scripts/validate_outputs.py --run-dir ../synthetic-run
```

运行器默认使用原实验的3个种子。仅检查输入与队列构造可加 `--prepare-only`；加 `--seeds 42` 可以做单种子烟测，但该设置不等于原实验的3次重复。通用代码使用不带固定人数的队列名称，与公开结果的名称对应见输入规范。
